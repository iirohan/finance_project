This repository contains a collection of Jupyter Notebook (.ipynb) files. Each notebook is self-contained and can be run independently to reproduce the corresponding results.\n
prepare_dataset.ipynb creates HeteroData files for Baseline models - GCN, GAT and TransformerConv.\n
prepare_dataset-edge.ipynb creates HeteroData file for proposed model.\n
GCN.ipynb, GAT.ipynb and TransformerConv.ipynb were used to test homogeneous graphs.\n
GCN+FC.ipynb, GAT+FC.ipynb and TransformerConv+FC.ipynb have the test results for baseline heterogeneous models.\n
RandomForest.ipynb has test results for baseline randomforest model.\n
ProposedModel.ipynb has test results for the proposed model.\n
